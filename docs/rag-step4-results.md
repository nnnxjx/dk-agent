## 语料与题目

7 份仓库文档快照、7 个独立评测知识库、29 个分块；分块大小 1000、重叠 200。107 道有答案题，开发集 81 道、保留测试集 26 道；本轮未运行保留测试集。

原文与标签由本轮 Agent 关联并验证，未经过独立人工审核；本轮为文档问答，不是文档中业务功能的运行验收。仍是有限规模的首轮扩充，没有覆盖 PDF 解析和真实用户流量。

## 问答阶段

生成及评审：deepseek/deepseek-chat，temperature=0；重排=true，模型=BAAI/bge-reranker-v2-m3。Embedding 为 BAAI/bge-m3。

每题独立运行真实 Supervisor→Agent→知识库工具→Milvus→生成。直接调用 AgentService，不覆盖 HTTP、登录鉴权及会话持久化；不开放 web/MCP。Agent 自主选择 query、TopK、检索次数，不能将其回答成绩解释为固定 Top3 的生成成绩。

## 结论与限制

本轮建立更大文档题库的开发基线，不将其与旧合成题库成绩直接相减来宣称算法提升。关闭重排的对照需在同一语料、问题及 TopK 下另跑；本轮摘要默认只描述启用重排的运行。

原第一至三步数据与无答案场景不改。本轮不评估无答案拒答、知识库外问题、PDF 解析或并发负载；检索和问答可能并行运行，顺序请求耗时不代表生产 SLA。生成 Token 与成本不可用。下一步先审核标签及失败样例，再决定优化；保留测试集留到方案冻结后执行。

验证：14 项本地评测测试通过；107 题原文、行号、来源、划分与分块可匹配性检查通过。
