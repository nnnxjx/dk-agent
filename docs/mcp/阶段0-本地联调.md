# 阶段 0 本地联调说明（纯 HTTP）

## 1. 目标

在不改业务代码的前提下，验证：

- 后端能用 `StreamableHTTPClientTransport` 连接 MCP Server；
- 能 `listTools`、`callTool`、`close`；
- 现有 `web_search`、`rag_retrieval` 不受影响。

## 2. 最小测试 Server（不新增依赖）

用已安装的 `@modelcontextprotocol/sdk@1.30.0` 自带的
`McpServer + StreamableHTTPServerTransport` 起服务。

> 注意：不要把测试 Server 接入生产配置，只跑本地 `http://localhost`。

### 2.1 启动测试 Server

```bash
MCP_TEST_PORT=3100 npx ts-node --transpile-only scripts/mcp/test-http-server.ts
```

服务监听：`http://localhost:3100/mcp`，提供 `echo` 工具。

### 2.2 客户端验证

另开一个终端：

```bash
MCP_TEST_URL=http://localhost:3100/mcp npx ts-node --transpile-only scripts/mcp/test-http-connection.ts
```

预期输出示例：

```text
Connected in 123ms
Tools: echo
Tool output: echo: hello-mcp
```

脚本内部调用的是 `src/mcp/mcp-connection.manager.ts` 的
`testConnection` 与 `callTool`，每次新建 Client + Transport，用完即 close。

## 3. 基线单测

```bash
npx jest src/mcp/mcp.connection.spec.ts --runInBand
```

覆盖 URL 协议校验、localhost 例外、鉴权头白名单，不触碰内置工具。

## 4. 验收

- [ ] 测试 Server 可启动并接受 `/mcp` 请求
- [ ] `listTools` 能看到 `echo`
- [ ] `callTool` 返回 text 内容块
- [ ] `close` 后无残留连接
- [ ] 没有提交任何密钥到仓库
- [ ] `pnpm lint` / `pnpm build` 通过，原有对话流程不受影响
